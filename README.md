# Obsidian Table Exporter

Утилита для преобразования таблиц из Obsidian в отдельные заметки с YAML frontmatter.

---
## 🚀 Возможности

- Преобразует таблицы Markdown в отдельные заметки
- Сохраняет данные в формате YAML frontmatter
- Автоматически генерирует безопасные имена файлов
- Выводит подробную статистику процесса

---
## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com//card-note-converter.git
cd card-note-converter
```

2. Убедитесь, что у вас установлен Python 3.6+

---
## 🛠 Использование

1. Поместите вашу заметку с таблицей в удобное место
2. Запустите скрипт:

```bash
python src/сonverter.py
```

3. После запуска введите в терминал:
	- Путь к исходной заметке
	- Путь к папке для экспорта

---
## 📝 Формат входных данных

Ваша заметка должна содержать таблицу под заголовком `## Список фриланс-бирж`:

```markdown
## Список фриланс-бирж

| Название | Ссылка | Актуальность |
|----------|--------|--------------|
| Fiverr   | https://threee.com | 5 |
| Upwork   | https://work.com | 4 |
```

---
## 📂 Выходные данные

Скрипт создаёт отдельные файлы в указанной вами папке при запуске по примеру 👇

```terminal
File.name.md

---
Ссылка: https://threee.com
Актуальность: 5
---
```
